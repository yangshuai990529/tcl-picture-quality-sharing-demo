# TCL 电视画质方案管理 Demo

这是一个无需安装依赖的静态 Demo，按 TCL 电视端「图像设置」新增能力的视觉方向实现：深色设置层级、左侧导航、遥控器焦点、红色主确认操作。

## 运行

在本目录执行：

```bash
python3 -m http.server 4173
```

然后访问：`http://127.0.0.1:4173/`

## 已实现流程

1. **画质参数分享**：选择信号类型和图效 → 输入方案名称 → 按电视菜单分组预览“设置项名称：当前方案值” → 生成分享码。
2. **导入分享码**：输入8位数字分享码（演示码：`5837 2416`） → 预览同一套参数 → 可保存到“我的方案”或确认应用。分享码实际按8位数字存储与校验，界面每4位显示一个空格。
3. **自动备份与我的方案**：应用前自动备份当前图效参数；方案可在「我的方案」中查看、应用、分享、删除。
4. **遥控器模拟**：支持方向键切换当前页面的可操作焦点，`Enter` 触发操作，`Esc` 关闭弹窗。

## 参数来源

`data/quality-menu-parameters.json` 从用户提供的：

`画质 灵悉UI V5.2_中国区设置Menu_Tree.xlsx`

提取而来，原始数据保留前六列菜单信息。预览界面不再展示表格或默认值，只显示各功能的设置项名称和 Demo 中模拟的当前用户方案值。

原始菜单共 75 条非空记录。

## 首页入口与自适应布局

- Demo 现从「安全卫士」首页开始。点击 **画质方案管理**（或关联入口 **备份与恢复**）进入画质方案管理。
- 在方案管理页左上可点击 `‹ 安全卫士` 返回首页。
- 横屏电视布局会随视口宽高缩放：4K / 1080P 保持单屏结构；较窄屏幕自动收紧侧栏、卡片和参数网格；手机宽度下则切换为纵向布局。

## 遥控器交互

- `↑ / ↓ / ← / →`：在当前页面的可操作控件之间移动焦点，按照屏幕空间位置选择最近的控件。
- `Enter / NumpadEnter`：确认当前焦点；输入分享码或方案名称时，会直接触发对应的下一步操作。
- `Esc / Backspace / BrowserBack / GoBack / Back`：执行电视遥控器返回；弹窗中关闭弹窗，方案详情返回列表，管理页面返回安全卫士首页。
- 重新渲染页面或切换选项后，焦点会按照当前选择项恢复，不会跳回无关控件。
